# SaaS Frontend

Frontend em Next.js (App Router) para consumir a API Nest existente. Configure `NEXT_PUBLIC_API_URL` para apontar para o backend (por exemplo, `http://localhost:3000`).

## Scripts
- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`
- `npm run typecheck`

## Stack
- Next.js 15
- React 18
- Tailwind CSS
- TypeScript
